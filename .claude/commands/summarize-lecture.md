description: 오늘(또는 지정한 날짜) 강의노트를 정리해서 고정 템플릿으로 요약합니다.
---

강의노트를 정리해줘.

1. 날짜는 `$ARGUMENTS`가 주어지면 그 날짜(YYYY-MM-DD)를 쓰고, 없으면 오늘 날짜를 쓴다.
2. `강의노트/{날짜}/` 폴더 안의 원본 텍스트 파일들(보통 `원본.md`)을 모두 읽는다.
   폴더나 파일이 없으면 `강의소스/{MMDD}/` 에 `.mhtml` 저장본이 있는지 확인한다.
   - 있으면 `lecture-extract` 스킬로 `원본.md` 를 먼저 만들지 사용자에게 물어본다.
   - 그것도 없으면 사용자에게 알리고 멈춘다. 원본 없이 요약을 지어내지 않는다.
3. `강의노트/TEMPLATE.md`의 구조를 그대로 따라서 요약을 작성한다.
   - `강의일자`는 위 1번의 날짜.
   - `정리작업시각`은 지금 실제 현재 시각(이 명령을 실행하는 시점)으로 채운다. 강의일자와
     다른 날짜/시각이어도 그대로 둔다 (언제 정리 작업을 했는지 기록하는 용도).
   - 핵심 요약 / 상세 내용 / 느낀 점 섹션을 원본 내용에 맞게 채운다. 원본에 없는 내용을
     지어내지 않는다.
4. 결과를 `강의노트/{날짜}/summary.md`로 저장한다.
5. 저장 후, 블로그(`blog_ksk`)에도 올릴지 사용자에게 물어본다 (자동으로 올리지 않는다).
