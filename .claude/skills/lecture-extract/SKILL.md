# 강의 mhtml → 원본.md

강의를 정리하려면 원본 텍스트가 먼저 있어야 하는데, 저장된 원본은 브라우저가 통째로
저장한 `.mhtml` 이라 그냥은 읽을 수 없다. 이 스킬이 그 한 단계를 담당한다.

**이 작업은 이미 네 번 반복됐다** (`강의소스/0901~0904/word작업/extract.py` 가 매번 조금씩
다른 사본으로 존재한다). 그래서 스크립트를 하나로 고정했다 — 새로 짜지 말고 이것을 쓴다.

## 전체 흐름에서 어디쯤인가

```
강의소스/{MMDD}/*.mhtml            ← 브라우저로 저장한 강의 원본 (제3자 저작물)
        │
        │  ① 이 스킬
        ▼
강의노트/{YYYY-MM-DD}/원본.md      ← 추출된 본문 (.gitignore 대상, 커밋 금지)
        │
        │  ② /summarize-lecture {날짜}
        ▼
강의노트/{YYYY-MM-DD}/summary.md   ← 내가 정리한 요약 (커밋함)
        │
        │  ③ /blog-post {날짜}
        ▼
blog_ksk/_posts/{날짜}-{슬러그}.md  ← 공개 블로그 글
```

## 쓰는 법

프로젝트 루트(`C:\AI-Agent`)에서 실행한다.

```bash
PYTHONIOENCODING=utf-8 python .claude/skills/lecture-extract/mhtml2md.py 2026-09-07
```

| 인자 | 뜻 |
|---|---|
| `2026-09-07` 또는 `0907` | 날짜. 둘 다 받는다 |
| `--list` | 파일별 step 번호만 출력. 파일을 만들지 않는다 |
| `--force` | 이미 있는 `원본.md` 를 덮어쓴다 |

`PYTHONIOENCODING=utf-8` 은 **생략하면 한글이 깨진다.** 윈도우 콘솔 코드페이지 문제다.

## 강의 URL 로 어느 강의인지 찾기

사용자가 `https://learn.modulabs.co.kr/camp/147/courses/2190/node-version/5312/steps/26788`
같은 주소를 주면, 로그인이 걸려 있어 웹으로는 못 읽는다. 저장본에서 찾는다:

```bash
PYTHONIOENCODING=utf-8 python .claude/skills/lecture-extract/mhtml2md.py 0907 --list
```

```
 26783  1.어시스턴트에서 에이전트로 - 도구의 정체 _ 모두의연구소.mhtml
 26788  4.하네스 종류 - 어떤 AI 코딩 도구를 고를까 _ 모두의연구소.mhtml
```

어느 날짜 폴더인지 모르면 여러 날짜로 `--list` 를 돌려 본다. step 번호는 날짜순으로
증가하므로(0904 는 26754~26769, 0907 은 26783~26789) 대략 짐작할 수 있다.

## 알아 둘 것

### 강의는 평일에만 열린다 — 주말·공휴일은 건너뛴다

**폴더 이름을 +1 하다 주말을 건너뛰지 않으면 날짜가 어긋난다.** 실제로 겪은 일이다 —
`0904`(금) 다음 강의를 `0905` 로 저장했는데 2026-09-05 는 **토요일**이었고, 실제 강의는
`0907`(월)이었다. 요약과 블로그 글까지 다 만든 뒤에 발견해서 전부 되돌려야 했다.

그래서 스크립트가 먼저 막는다. 주말이나 공휴일 날짜를 주면 실행하지 않고 알려준다.

```
2026-09-05 은 토요일 (주말) 이라 강의가 없습니다.
강의는 평일에만 열립니다 — 폴더 이름이 잘못됐을 가능성이 큽니다.
다음 강의일은 2026-09-07 (월) 입니다.
폴더 이름을 먼저 고치세요:  mv 강의소스/0905 강의소스/0907
```

- **주말**은 자동으로 걸러진다.
- **공휴일**은 `강의노트/휴일.txt` 에 한 줄씩(`YYYY-MM-DD`) 적어 둔 것만 걸러진다.
  새 공휴일이 생기면 그 파일에 추가한다 — 스크립트가 달력을 알지는 못한다.
- 날짜가 정말 맞다면(보강 등) `--any-day` 로 검사를 건너뛴다.

날짜를 다룰 때는 **추측하지 말고 요일을 확인한다.**

```bash
date -d 2026-09-07 '+%a'
```

### 날짜 표기가 두 곳에서 다르다

| 폴더 | 표기 | 예 |
|---|---|---|
| `강의소스/` | **MMDD** | `강의소스/0907/` |
| `강의노트/` | **YYYY-MM-DD** | `강의노트/2026-09-07/` |

스크립트가 변환해 주지만, 손으로 경로를 쓸 때 자주 틀린다.

### step 번호는 HTML 본문에 없다

`.mhtml` 의 **MIME 헤더**(`Content-Location`, `Snapshot-Content-Location`)에 원래 주소가
들어 있다. HTML 본문을 grep 해도 안 나온다 — 본문에는 `data-steps-list-container` 같은
속성만 있다. (원본 파일을 raw 로 grep 하면 헤더까지 훑기 때문에 찾아지는데, 파싱한
HTML 에서는 안 보여서 헷갈리기 쉽다.)

### 걷어내는 것

`nav` · `aside` · `header` · `footer` · `button` · `title` 태그를 통째로 버린다. `aside` 는 강의 목록
사이드바여서 남기면 "대기중", "00:00:12" 같은 진행 표시가 본문에 섞인다.
`진행 중 학습으로 이동`, `오늘 하루 보지 않기` 같은 화면 문구도 걸러낸다.

기존 `강의소스/0904/텍스트추출/*.md` 에는 이 장식 문구가 그대로 남아 있다 — 그 결과물을
재사용하지 말고 이 스크립트로 다시 뽑는다.

### 그림은 뽑지 않는다

본문 텍스트만 뽑는다. 그림이 필요하면 `강의소스/0904/word작업/extract.py` 가 이미
`images/` 로 뽑아 `build.js` 로 워드 문서를 만드는 경로가 있으니 그것을 쓴다.

## 저작권 — 이게 제일 중요하다

추출한 `원본.md` 는 **원본 강의와 똑같은 제3자 저작물**이다 (모두의연구소).

- 루트 `.gitignore` 에 `강의노트/*/원본.md` 와 `강의소스/` 가 이미 들어 있다. **이 규칙을 풀지 않는다.**
- 커밋하는 것은 내가 직접 쓴 `summary.md` 뿐이다.
- 블로그에 올릴 때도 원문을 그대로 옮기지 않는다 — 요약·재구성만 올린다.
- 새 날짜 폴더를 만든 뒤 `git status` 에 `원본.md` 가 보이면 `.gitignore` 규칙이 깨진 것이니
  커밋하지 말고 먼저 확인한다.

## 끝난 뒤

`원본.md` 가 만들어졌으면 사용자에게 알리고 다음 단계를 물어본다:

```
/summarize-lecture 2026-09-07
```

원본을 만들었다는 이유로 요약까지 자동으로 진행하지 않는다.
