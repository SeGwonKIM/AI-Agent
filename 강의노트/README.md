# 강의노트 폴더

매일 듣는 강의 원본 내용을 정리하기 전 단계로 모아두는 전용 폴더입니다.

## 사용법

1. 강의를 들은 날짜로 폴더를 만듭니다: `강의노트/YYYY-MM-DD/`
2. 그 안에 원본 노트/스크립트 텍스트 파일(.txt, .md 등)을 넣어둡니다.
3. `/summarize-lecture` 명령을 실행하면, 그 날짜 폴더의 원본을 읽어서
   `TEMPLATE.md` 형식에 맞춰 `강의노트/YYYY-MM-DD/summary.md`로 정리합니다.

## 강의 일정

강의는 평일에만 진행됩니다 (토요일, 일요일, 공휴일 없음).

## 참고

- `TEMPLATE.md`: 정리 결과가 항상 따르는 고정 틀
- 블로그(`blog_ksk`)에 올리고 싶으면 정리 후 별도로 요청하면 됩니다.
