① 종류 — 기본 공식

에이전트 = 모델 + 하네스

🧠 모델 = 두뇌

생각하는 부분. Claude, GPT, Gemini…두뇌만 있으면 생각만 하고 끝난다

🦾 하네스 = 손발 + 작업장

파일을 읽고 고치고, 명령을 실행하고, 결과를 다시 보는 몸원래 뜻은 말에 채우는 마구·안전벨트

같은 모델이라도 하네스가 다르면 결과가 다릅니다
— 도구를 고른다 = 하네스를 고른다
① 종류 — 네 부류가 전부

하네스 4종 — 어디서 돌고, 얼마나 지켜보나

🖱️ 브라우저형

웹에서 클릭으로 만들고 배포까지. 문턱이 가장 낮음Lovable · Bolt · Replit — 무인 키오스크 느낌

📝 편집기형

고친 걸 눈으로 보며 승인·취소Cursor · Copilot · Cline — 옆자리 동료 느낌

⌨️ 터미널형

검은 명령창. 깊고 강력하지만 낯섦Claude Code · Codex CLI · agy · Aider

☁️ 클라우드형

통째로 맡기면 알아서, 결과는 초안Devin · Google Jules — 배달 주문 느낌

앞의 셋 = 내가 지켜보는 쪽 · 마지막 = 멀리 맡기는 쪽

② 기준 — 정답이 아니라 내 조건

고를 때 볼 다섯 가지

  1. 모델을 골라 쓸 수 있나 — 한 회사 것만? 아무 모델이나 꽂나?
  2. 비용 구조 — 월 정액인가, 쓴 만큼 API 요금인가 (후자는 확 오른다)
  3. 오픈소스인가 — 회사가 접어도 남이 이어받아 살릴 수 있다
  4. 터미널이 편한가 — 편하면 CLI형, 아니면 편집기형
  5. 맡길까 지켜볼까 — 승인하며 갈지, 결과만 검토할지

실무자도 하나만 쓰지 않습니다. 어려운 건 터미널, 일상 편집은 편집기, 가끔 클라우드.

③ 안전 — 컴퓨터를 맡긴다는 뜻

에이전트는 실제로 파일을 지웁니다

사람들은 권한 요청의 약 93%를 그냥 승인합니다

도구가 "이거 해도 될까요?"를 물어도, 반복되면 무심코 '예'를 누르게 된다

1. 중요한 폴더에서 '자동 수락'을 켜지 않는다

문서·사진·회사 자료 폴더에선 매번 확인 모드로

2. 되돌릴 지점을 먼저 만든다

위험한 작업 전에 커밋 — 잘못돼도 그 지점으로 롤백

3. 핵심 한 문장

"아무것도 안 물어봄"과 "중요한 것 전체 접근"을 동시에 켜지 마라

④ 비용 — 토큰과 컨텍스트

왜 비싸고, 왜 길어지면 헤매나

토큰이 눈덩이가 되는 이유

루프를 여러 번 돌고, 매번 앞선 대화를 통째로 다시 읽는다보통 채팅의 4배 · 여러 에이전트 협업은 15배까지

컨텍스트 부패 (context rot)

대화가 길어져 한도가 차면 아까 정한 걸 잊고, 없는 파일명을 지어낸다책상에 서류가 쌓여 정작 필요한 걸 못 찾는 상태

해법 1 · 작게 쪼개기

거대한 작업을 통째로 시키지 않는다. 큰 파일은 필요한 부분만
