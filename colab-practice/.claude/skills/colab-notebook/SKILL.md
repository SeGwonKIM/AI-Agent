# colab-notebook

Colab MCP(`mcp__colab-mcp__*`)로 사용자가 브라우저에 열어 둔 Colab 노트북을 다룬다.
노트북은 사용자의 작업물이다. 남의 공책에 쓸 때처럼 **빈 자리에 덧붙이고, 원래 내용은 건드리지 않는다.**

## 1. 연결 준비

1. 노트북 도구는 처음에 지연 로드 상태다. 먼저 연결 도구를 불러와 연결한다.
   ```
   ToolSearch  select:mcp__colab-mcp__open_colab_browser_connection
   open_colab_browser_connection  → result: true 여야 연결 성공
   ```
2. `false` 가 나오면 진행하지 말고 사용자에게 알린다 — 브라우저에서 Colab 노트북 탭이
   열려 있는지, 런타임이 연결돼 있는지 확인해 달라고 한다. 같은 호출을 반복하지 않는다.
3. 연결에 성공하면 셀 도구가 새로 생긴다. **필요한 것을 한 번에** 불러온다.
   ```
   ToolSearch  select:mcp__colab-mcp__get_cells,mcp__colab-mcp__add_code_cell,mcp__colab-mcp__run_code_cell
   ```
   텍스트 셀·수정·삭제·이동이 필요할 때만 `add_text_cell`, `update_cell`, `delete_cell`, `move_cell` 을 추가한다.

## 2. 기존 셀 보존

1. 셀을 추가하기 전에 **항상 `get_cells` 로 현재 셀 목록을 먼저 본다.**
   셀 개수를 추측하지 않는다 — 추가 위치(`cellIndex`)가 여기서 정해진다.
2. 새 셀은 **맨 끝**(`cellIndex` = 현재 셀 개수)에 넣는다.
   중간에 끼워 넣으면 사용자의 셀 순서가 밀린다. 사용자가 위치를 지정했을 때만 예외.
3. 이미 있는 셀은 **비어 있어도** 덮어쓰거나 지우지 않는다.
   빈 셀도 사용자가 일부러 둔 것일 수 있다. 남겨 두고, 남겨 뒀다고 보고한다.
4. `update_cell` / `delete_cell` / `move_cell` 은 사용자가 그 셀을 콕 집어 요청했을 때만 쓴다.
   쓰기 전에 무엇을 바꾸는지 먼저 말한다.
5. 같은 대화에서 셀을 여러 번 추가할 때도 매번 셀 수를 다시 확인하거나,
   직전 추가 결과로 끝 위치를 정확히 계산한다.

## 3. 출력 확인

1. 셀을 추가했으면 `add_code_cell` 이 돌려준 `newCellId` 로 `run_code_cell` 을 실행한다.
   셀 번호가 아니라 **ID로** 실행한다.
2. 결과는 실행 출력(`outputs`)에서 읽은 값만 보고한다. 머릿속 계산으로 답을 대신하지 않는다.
3. 출력에 `error` 타입(트레이스백)이 있으면 성공이라고 하지 않는다.
   오류 이름과 메시지를 그대로 보여 주고, 원인과 고칠 방법을 제안한다.
4. 출력이 비어 있으면 그 사실을 말한다 (`print` 를 빠뜨렸는지 확인).
5. 보고에는 ① 결과 값 ② 실행한 코드 ③ 노트북의 몇 번째 칸에 추가했는지를 담는다.
6. 요청이 모호하면 (예: 명령어 이름만 던짐) Colab 문맥이면 **Colab 런타임** 기준으로 실행하고,
   로컬 PC 기준을 원했을 수도 있다고 한 줄 덧붙인다.
7. 런타임 고유값(호스트명, 경로, GPU 종류 등)은 런타임을 재시작하면 바뀔 수 있다고 알려 준다.

## 4. 연결 주소 보호

Colab 브라우저 연결 주소, 토큰, 런타임 접속 URL은 **노트북에 대한 열쇠**다.
가진 사람은 노트북의 코드를 실행할 수 있으므로 비밀번호처럼 다룬다.

1. 연결 주소·토큰·포트가 담긴 URL을 응답에 그대로 옮겨 적지 않는다.
   필요하면 "연결됨 / 연결 실패" 상태만 말한다.
2. 그런 값을 파일, 커밋, 강의노트, 블로그 글, README, PRD, 이 스킬 문서에 적지 않는다.
3. 노트북 셀에도 하드코딩하지 않는다. 노트북은 공유·다운로드되기 쉽다.
   API 키 같은 비밀값이 필요하면 Colab의 `google.colab.userdata`(보안 비밀 패널)를 쓰게 안내한다.
4. 노트북 출력에 토큰·키·연결 주소로 보이는 값이 나오면 그대로 인용하지 말고 가린 채(`abc…xyz`) 보고한다.
5. 연결 주소를 외부 서비스나 다른 도구로 보내지 않는다.

## 하지 말 것

- `get_cells` 없이 셀 위치를 짐작해 추가하기
- 빈 셀이라고 지우거나 덮어쓰기
- 실행하지 않고 "결과는 ~입니다" 라고 답하기
- 연결 주소·토큰을 화면, 파일, 노트북 어디에든 남기기
